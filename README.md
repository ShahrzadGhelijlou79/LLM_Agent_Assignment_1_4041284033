### ۱. نصب پکیج‌ها

پیش از اجرای برنامه، کتابخانه‌ها و وابستگی‌های موردنیاز را با دستور زیر
نصب کنید:

``` bash

```

### ۲. دریافت مدل اصلی

مدل پیش‌فرض و تست‌شده این پروژه `qwen2.5-coder` است. برای دریافت آن از
طریق Ollama، دستور زیر را اجرا کنید:

``` bash
ollama pull qwen2.5-coder
```

> این مدل محلی به دسترسی اینترنت نیاز نخواهد داشت.

## شیوه اجرا

برنامه از طریق ترمینال و با دستور زیر اجرا می‌شود. مسیر فایل‌های ورودی و
خروجی را ارزیاب یا کاربر تعیین می‌کند:

``` bash
python main.py --input input.json --output output.json
```

### پارامترهای اختیاری

-   **`--model`**: برای تعیین دستی مدل مورد استفاده؛ برای مثال:

    ``` bash
    python main.py --input input.json --output output.json --model qwen2.5-coder
    ```

    اولویت انتخاب مدل به این ترتیب است:

    1.  آرگومان خط فرمان `--model`
    2.  متغیر محیطی `OLLAMA_MODEL`
    3.  مقدار تعریف‌شده در فایل تنظیمات `Source/config/evaluation.json`

-   **`--trace`**: برای ثبت جزئیات و لاگ‌های تکمیلی در یک فایل جداگانه؛
    برای مثال:

    ``` bash
    python main.py --input input.json --output output.json --trace trace.json
    ```

## ساختار داده‌های ورودی و خروجی

### قالب فایل ورودی (`input.json`)

``` json
{
  "id": "test_001",
  "problem": "شرح مسئله و قالب ساختاری پاسخ مورد انتظار"
}
```

### قالب فایل خروجی (`output.json`)

``` json
{
  "id": "test_001",
  "answer": "FINAL_ANSWER"
}
```

**توضیح:** فیلد `answer` صرفاً شامل پاسخ نهایی است. در صورت بروز خطای
بحرانی، فایل خروجی با پاسخ خالی تولید می‌شود و برنامه با کد خروجی غیرصفر
خاتمه می‌یابد.
